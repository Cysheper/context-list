# 竞赛日历前端

Vue 3 + Vite 的轻量赛事列表和详情页，无额外 UI 组件库。数据来自同级 `context-list-server/data.json`，通过现有 FastAPI 查询接口读取。

## 本地预览

终端一（后端）：

```bash
cd ../context-list-server
.venv/bin/python main.py
```

终端二（前端）：

```bash
npm install
npm run dev
```

前端接口统一使用 `/api` 前缀，当前查询地址为 `/api/get_all_contexts`，由 Nginx 负责转发。Vite 不配置接口代理。开发时请通过配置了 Nginx 转发的站点访问；直接访问 Vite 的 5173 端口只能预览前端，接口转发需要 Nginx。`npm run build` 生成 `dist/`，可供 Nginx 部署。

## 页面与交互

- `#/`：时间排序、搜索、赛事与状态筛选。
- `#/contest/{id}`：报名与选拔、能力建议、历届成绩和回顾。
- `#/saved`：当前浏览器的本地收藏，不发送提醒。
- 侧边栏月历按真实北京时间显示当前月份，支持翻月、回到本月、全部／收藏切换。点击比赛日期在月历下方显示当天赛事，点击赛事进入详情，跨日比赛标记每个比赛日；待定赛事不标入月历。
- 包含加载失败、空结果和详情不存在状态，适配移动端。

全部赛程、名单和统计均为演示数据。月历使用真实日期。为了让列表和详情的样例状态稳定可复现，其状态时间基准固定为 `2026-09-20 09:00 +08:00`，定义于 `src/lib/contests.js`；接入真实数据时应替换为实际时钟。报名入口和照片未虚构外部链接。

## 赛事新闻与 Markdown

- `#/news`：文章列表，可按获奖喜报、赛事回顾、备赛动态筛选与搜索。
- `#/news/{id}`：文章详情，支持刷新直达、相关资讯和关联比赛跳转。
- 在 `src/content/news/index.js` 添加文章标题、摘要、分类、发布时间等信息，再新增同名 `{id}.md` 正文即可。此阶段使用前端文件内容，无需修改后端接口。
- 支持 Markdown 标题、列表、任务列表、表格、引用、链接、图片及代码块。使用 marked 解析、DOMPurify 清理 HTML；外部网页链接在新窗口打开。正文按需加载。
- 图片放在 `public/news/`，正文使用 `![图片说明](/news/文件名.jpg)`。现有 SVG 均为明确标记的示意插画，不是学校实拍照片；替换成真实图片时也应更新相应说明。
